# v0.1.4y (프리릴리즈)

## 자동 재빌드 및 패키지 업데이트 개선

- MSHELL Manager의 헤드리스 로더 자동 재빌드 경로를 추가했습니다.
- 이제 `my()`를 호출하기 전에 비대화형 모드를 명시적으로 활성화하여 `getlatestmshell()`이 `noask` 모드로 실행되고 터미널 입력을 기다리지 않습니다.
- 최신 패키지 선택과 해시 검증을 개선하여 오래된 로컬 파일에 의존하지 않고 릴리즈 메타데이터가 지정한 정확한 SPK를 준비합니다.
- 릴리즈 메타데이터 조회, 다운로드, SHA-256 검증이 실패했을 때 원인을 확인할 수 있도록 처리와 로그를 보완했습니다. 선택적 패키지 다운로드 실패가 전체 로더 빌드를 조용히 중단시키지 않습니다.
- 자동 빌드에서 사용하는 모델 및 릴리즈 메타데이터를 새로 확인하도록 하여 오래된 세션 파일을 잘못 재사용하는 문제를 줄였습니다.

이 릴리즈는 자동 재빌드 및 자동 업데이트 흐름을 검증하기 위한 프리릴리즈입니다. 실기 전체 테스트가 완료되기 전까지 안정 버전 로더 릴리즈로 사용하지 않는 것을 권장합니다.
