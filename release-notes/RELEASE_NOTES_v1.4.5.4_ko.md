# alpine-redpill v1.4.5.4

## 원격 로더 패키지의 안전성 개선

원격 로더 업데이트용 파일을 만들 때 부팅 파일이 빠져 있으면 대상 장비에서 사용할 수 없는 패키지가 만들어질 수 있었습니다. 이제 로더 파티션의 마운트 상태와 필수 파일을 확인하고 완성된 압축파일을 검증하며, 기존 패키지를 덮어쓰지 않습니다.

P3의 `xtcrp.tgz` 백업도 패키지에 포함합니다. 백업 파일이 없거나 손상되었으면 불완전한 업데이트 파일을 배포하지 않고 오류를 표시합니다.

## Docker 빌드 환경 보호

Docker를 이용한 로더 빌드에서 호스트 디스크를 로더 이미지로 잘못 선택하면 다른 장치를 대상으로 작업할 위험이 있습니다. Docker 빌더 모드를 명시적으로 켠 경우 지정된 loop 이미지와 4개 파티션 장치를 확인하고, 파티션 계산에 해당 loop 디스크를 사용합니다. DSM 호스트의 MMC 모듈 탐색과 스왑·캐시 조작도 건너뜁니다. Alpine 영속화 단계에서는 임시 백업 위치의 설정과 실제 백업 파일 생성을 확인합니다.
