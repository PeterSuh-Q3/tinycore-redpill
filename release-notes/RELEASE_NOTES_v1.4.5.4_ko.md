# alpine-redpill v1.4.5.4

## 불완전한 원격 로더 업데이트 방지

원본 로더의 파일이 빠진 상태로 업데이트 패키지를 만들면 원격 장비가 부팅되지 않을 수 있습니다. 이제 무엇이 부족한지 안내하고 패키지 생성을 중단합니다. 기존 패키지도 조용히 덮어쓰지 않습니다.

로더 백업인 `xtcrp.tgz`도 업데이트 파일과 함께 전달됩니다. 이 백업이 없거나 손상되었다면 원본 로더의 백업을 먼저 복구한 뒤 패키지를 다시 만드세요.

## Docker 빌드 중 NAS 보호

NAS의 Docker 컨테이너에서 로더를 빌드할 때 빌드용 이미지와 NAS의 실제 디스크를 혼동하면 호스트 저장장치가 위험해질 수 있습니다. 이제 Docker 빌더 모드에서는 지정한 이미지가 확인되지 않으면 진행하지 않고, 호스트의 모듈·스왑·캐시를 건드리지 않습니다. 필요한 Alpine 영속화 백업이 실제로 만들어지지 않았을 때도 중단합니다. 이 보호는 Docker 빌더 모드를 명시적으로 켠 경우에만 적용되며, 일반 실기 빌드 방식은 바뀌지 않습니다.
