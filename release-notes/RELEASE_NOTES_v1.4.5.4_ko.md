# alpine-redpill v1.4.5.4

## 불완전한 원격 로더 업데이트 방지

원본 로더의 파일이 빠진 상태로 업데이트 패키지를 만들면 원격 장비가 부팅되지 않을 수 있습니다. 이제 무엇이 부족한지 안내하고 패키지 생성을 중단합니다. 기존 패키지도 조용히 덮어쓰지 않습니다.

로더 백업인 `xtcrp.tgz`도 업데이트 파일과 함께 전달됩니다. 이 백업이 없거나 손상되었다면 원본 로더의 백업을 먼저 복구한 뒤 패키지를 다시 만드세요.

## MSHELL Manager의 Docker 원격 빌드 준비

MSHELL Manager에서 로더에 직접 진입하지 않고 Docker 컨테이너로 로더를 원격 재빌드해, 원본 로더의 DSM 커널을 교체할 수 있도록 하는 기능을 준비 중입니다. 이번 버전은 그 빌드에 필요한 로더 측 기반을 마련했습니다. 빌드 결과를 원본 로더에 적용하는 과정은 Manager에서 별도로 검증하고 사용자가 승인하도록 설계되어 있으며, 아직 완성된 원격 빌드 기능의 배포를 뜻하지는 않습니다.

Docker 빌더 모드에서는 지정한 빌드용 이미지가 없으면 중단하고 NAS 호스트의 디스크·모듈·스왑·캐시를 변경하지 않습니다. 일반 실기 빌드 방식은 바뀌지 않습니다.
