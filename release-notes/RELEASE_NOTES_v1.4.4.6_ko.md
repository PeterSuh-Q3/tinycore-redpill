# alpine-redpill v1.4.4.6

## 알파인 영속화 및 설정 안정성

- 알파인 영속화 파일을 임시 staging 위치에서 먼저 생성하고 검증한 뒤 활성 파일로 교체하도록 개선했습니다.
- 재부팅 후에도 `/home/tc/user_config.json`이 로더 파티션을 가리키는 심볼릭 링크로 유지됩니다.
- 모든 사용자 설정 저장을 검증된 안전 저장 함수로 통합해 잔여 임시 파일과 권한 변경 문제를 줄였습니다.
- 기존 설정 파일의 소유권을 보존하고 심볼릭 링크가 일반 파일로 바뀌지 않도록 수정했습니다.
- 로더 빌드 직후 영속화 기준값을 갱신해 즉시 재부팅할 때 중복 백업이 발생하지 않도록 했습니다.

## 이미지 빌드 일관성

- 이미지 빌드 워크플로우가 워크스페이스의 최신 `localhost.apkovl.tar.gz`를 생성 이미지의 p3 파티션과 알파인 파티션에 함께 복사합니다.
- 새 이미지가 빌드에 사용된 알파인 overlay와 동일한 상태를 유지하도록 보완했습니다.
