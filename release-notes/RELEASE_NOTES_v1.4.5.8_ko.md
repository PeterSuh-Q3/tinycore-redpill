# alpine-redpill v1.4.5.8

## 로더에서 설치된 DSM 상태 확인

로더는 부팅되지만 DSM 문제를 진단해야 할 때, 선택한 모델만으로는 디스크에 실제 설치된 DSM 버전이나 시스템 파티션의 구성을 알기 어렵습니다. 시스템 모니터에 선택한 Synology 모델과 설치된 DSM 버전을 한 줄로 표시하고, md0 RAID 구성원도 한 줄로 보여줍니다. md0를 읽기 전용으로 조립할 수 없는 경우에는 일치하는 RAID1 구성원에서 정보를 읽되, 배열 상태를 **미검증**으로 명시합니다. 구성원 목록만으로 RAID가 정상이라고 판단하지 않습니다. 값이 없거나 `None`인 보드 항목과 스왑이 없는 시스템의 빈 행도 숨깁니다.

## DSM에서도 보드 정보 활용

일부 DSM 환경에서는 물리 보드의 DMI 정보가 보이지 않아 로더 설정 때 확인한 보드 정보를 DSM 쪽 도구에서 활용하기 어렵습니다. 새 로더 빌드는 저장된 `general.board` 값을 `/addons/DMI`에 기록합니다. `cpuinfo` addon을 포함했고 해당 파일이 있으면 부팅 훅이 `/usr/mshell/DMI`로 복사하여 DSM 측에서 읽을 수 있게 합니다. 이 스냅샷을 넣으려면 **로더를 재빌드**해야 합니다. 저장된 `general.board`가 없는 자동 빌드에서는 보드 정보를 임의로 만들지 않습니다.

## xTCRP 이미지와 디스크 작업 정리

xTCRP 이미지 워크플로우가 다운로드 가능한 기본 이미지를 가진 이전 릴리즈를 인증된 방식으로 조회해, 비인증 조회 때문에 이미지 선택이 실패하는 경우를 줄였습니다. 로더 주입·제거 메뉴는 Synology 디스크 및 파티션 작업과 같은 곳으로 이동해 찾기 쉬워졌습니다.
