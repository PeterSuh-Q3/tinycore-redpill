# alpine-redpill v1.4.7.3

## DSM 주니어 Wi‑Fi 설정

기존에는 DSM 주니어의 무선 연결을 위해 설정 파일을 직접 편집해야 하는 경우가 있었고, 로더가 아직 네트워크에 연결되지 않았다면 특히 번거로웠습니다. 이제 메뉴에서 액세스 포인트를 검색하거나 SSID를 직접 입력해 WPA2-Personal 설정을 저장할 수 있습니다. 변경 사항을 적용하려면 로더를 다시 빌드해야 하며, 호환되는 무선 어댑터와 드라이버가 필요합니다. 인증 정보는 설정 파일과 생성된 initrd에 포함되므로 로더 파일을 안전하게 보관하십시오.

## Intel Mac USB 부팅 호환성

Intel 기반 MacBook과 Mac mini에서는 USB 컨트롤러 라우팅이 잘못 전달되어 DSM이 로더의 USB 파티션을 찾지 못할 수 있습니다. 이번 변경은 Intel Mac 전반의 호환성을 목표로 조기 xHCI 라우팅 보정을 추가합니다. 다만 자동 보정은 현재 확인된 MacBookPro11,1 컨트롤러와 검증된 레지스터 상태에서만 실행되며, 다른 Mac 모델은 아직 검증되지 않아 변경하지 않습니다.

## Gen8 CPU 호환성 안내

Atom 계열이 아닌 Intel 3세대 이하 CPU를 사용하는 Gen8 시스템에서는 더 높은 CPU 세대가 필요한 모델 설치를 권장하지 않습니다. Denverton(DVA3221), Apollo Lake(DS918+), Gemini Lake(DS920+) 모델은 Gen8에서 커널 패닉이나 멈춤을 일으킬 수 있어 해당 조건에서는 모델 메뉴에 표시되지 않습니다.
