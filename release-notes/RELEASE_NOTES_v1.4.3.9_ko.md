# alpine-redpill v1.4.3.9

## 제약된 네트워크용 GitHub 접속 모드

- 메인 메뉴에 **GitHub 접속 DNS 모드**를 추가했습니다. 일반 DNS 모드를 유지하거나 중국 사용자를 위한 선택적 **DoH 우회 모드**를 사용할 수 있습니다.
- 저장소 다운로드가 시작되기 전 GitHub 접속에 실패하면 DoH 우회 사용 여부를 다이얼로그로 안내합니다. Cloudflare DoH로 필요한 GitHub 도메인을 해석하고, 결과 호스트 매핑을 즉시 적용합니다.
- 일반 DNS 모드로 돌아가면 MSHELL이 추가한 리졸버와 호스트 항목만 제거합니다.

## 시작 시 로케일 안내

- 로더의 네트워크 대기 이후 현재 국가를 감지하고, 메뉴 언어가 아직 영어인 경우 감지된 지역 언어로 변경할지 현지화된 다이얼로그로 안내합니다.
- GitHub 검사와 저장소 checkout 전 단계에서 동작하면서도, 자동 SX 시작 시 초기 DHCP 및 DNS 경쟁으로 팝업이 누락되던 문제를 피합니다.
- 관련 다이얼로그 메시지를 지원하는 전체 언어 카탈로그에 확장했습니다.

## 다운로드 진행 상태

- MSHELL Manager, Syno Smart Info, Intel GPU Top, AMDGPU 패키지를 포함한 SPK 내장 다운로드의 진행률 표시를 통일했습니다.
