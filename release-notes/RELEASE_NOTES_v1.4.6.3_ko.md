# alpine-redpill v1.4.6.3

## 구형 CPU 호환성 점검 보완

일부 구형 x86 시스템은 저장된 모듈팩 설정이 CPU에서 지원하지 않는 명령어를 요구하면 로더 메뉴에 진입하기 전에 부팅이 멈출 수 있습니다. BMI2 미지원이 확인된 경우에는 메뉴를 표시하기 전에 사용 가능한 호환 custom-modules 모드로 설정을 자동 조정합니다. 선택한 DSM 모델이나 버전은 바꾸지 않습니다.

로더 빌드가 완료되면 DSM initrd 안의 지정된 파일을 대상으로 호환성 검사를 수행하고, 이미지 빌드에서는 최종 Alpine 및 xTCRP 이미지의 GRUB 파일도 검사합니다. 결과는 명령어 패턴의 정적 탐지와 실제 실행 실패 확인을 구분해 빌드 로그 마지막에 보여주므로, 이미지를 기록하거나 부팅하기 전에 호환성 위험을 파악하는 데 도움이 됩니다.

이 검사는 정적·참고용이며 모든 구성요소가 대상 CPU에서 정상 실행됨을 보장하지 않습니다. 검사 결과로 빌드를 차단하지 않으며, 영향을 받는 하드웨어에서 실제 부팅을 확인해야 합니다.
