# alpine-redpill v1.4.5.0

이번 복구 버전은 로더 스크립트와 번들 아카이브를 v1.4.4.8 기준으로 되돌립니다. v1.4.4.9는 Alpine 영속화 P3/P4 파티션의 불안정성 때문에 배포를 중단했습니다.

- P3에는 저장소 오버레이를 비교용 `localhost.apkovl.baseline.tar.gz`로 보관합니다. 이 이름은 Alpine의 `*.apkovl.tar.gz` 부팅 자동 탐색 대상이 아닙니다.
- P4에는 Alpine 부팅과 `lbu` 영속화에 쓰이는 `localhost.apkovl.tar.gz`를 유지합니다.
- 이미지 빌드 시 기반 이미지가 없는 배포 중단 릴리즈는 건너뛰므로 v1.4.5.0은 v1.4.4.8 이미지를 기반으로 사용할 수 있습니다.
- 기존 설치본의 P3 파일은 검증 후 다음 재부팅 전에 이름을 변경합니다. 비교본이 이미 있으면 옛 파일을 `localhost.apkovl.withdrawn.tar.gz`로 보존합니다. 전환 실패 시 원본을 건드리지 않고 경고를 출력합니다.
- 기존 P3 파일의 이름 변경에 로더 재빌드는 필요 없지만, P3가 쓰기 가능해야 합니다. 다음 부팅 로그에서 P4 오버레이가 선택된 것을 확인해야 전환이 완료된 것입니다.
