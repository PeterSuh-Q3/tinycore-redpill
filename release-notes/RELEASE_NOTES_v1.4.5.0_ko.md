# alpine-redpill v1.4.5.0

v1.4.4.9는 Alpine 영속화 P3/P4 파티션의 불안정성 때문에 배포를 중단했습니다. v1.4.5.0은 v1.4.4.8의 로더 동작과 P3/P4 영속화 파일 배치를 그대로 복원합니다.

- P3의 `localhost.apkovl.tar.gz` 처리와 파일명은 v1.4.4.8 방식 그대로 유지합니다.
- `localhost.apkovl.baseline.tar.gz`로 이름을 바꾸거나 기존 파일을 자동 마이그레이션하는 로직은 포함하지 않습니다.
- P4 `lbu commit` 이후 시스템 파일 소유권이 바뀌는 문제는 원인과 결과를 충분히 검증할 때까지 별도 개선으로 보류합니다.
- 이미지 빌드 워크플로는 배포 중단으로 자산이 없는 이전 릴리즈를 건너뛰어 v1.4.4.8 이미지를 기반으로 사용합니다.
