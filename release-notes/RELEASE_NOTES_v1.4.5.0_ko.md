# alpine-redpill v1.4.5.0

> **v1.4.4.9 대신 v1.4.5.0을 사용해 주세요.** v1.4.4.9 배포 후 일부 시스템에서 P3/P4 마운트와 Alpine 영속화·파일 소유권이 불안정해져 다운로드 자산을 회수했습니다. 이번 버전은 검증된 v1.4.4.8 로더 동작을 유지하면서 해당 장애를 보완합니다. v1.4.4.9에서 도입한 구버전 선택 기능은 포함하지 않았습니다.

## 이번 릴리즈가 필요한 이유

- **로더 설정과 Alpine 부팅 상태를 안정적으로 보존하기 위해:** P3에 둔 영속화 비교본이 부팅용 영속화 파일로 오인될 수 있었습니다. 이제 P3 비교본은 별도 이름으로 보관하고, 실제 부팅용 영속화 파일은 P4에만 둡니다. 기존 P3 파일은 검증한 뒤 이름을 바꾸며 P4의 사용 중인 파일은 덮어쓰지 않습니다.
- **백업 후 관리자 권한을 잃는 일을 막기 위해:** 이전 영속화 과정에서는 보호된 시스템 파일의 소유권이 잘못 기록되어 재부팅 후 `sudo`를 사용할 수 없게 될 위험이 있었습니다. 이제 P4 파일을 교체하기 전에 소유권과 압축 내용을 검사하고 안전하지 않으면 중단합니다. FAT 파티션이 지원하지 않는 소유권 보존 복사 때문에 로더 빌드 마지막 백업 단계가 실패하던 문제도 피했습니다.
- **메뉴와 모니터가 같은 파티션을 중복 마운트하지 않도록 하기 위해:** 두 창이 함께 시작되어도 공통 마운트 작업을 순서대로 수행하고, 뒤에 실행된 쪽은 이미 마운트된 파티션을 재사용합니다. 테스트 실기에서는 재부팅 후 P1~P3가 각각 한 번씩 마운트됐고 설정 파일도 쓰기 가능했습니다.
- **이미 영향을 받은 시스템을 안전하게 복구하기 위해:** 중복 또는 잘못된 P3 마운트가 남은 시스템용 수동 복구 스크립트를 제공합니다. 변경 전에 대상을 검사하며, 이번 업데이트가 기존 파일시스템 손상을 자동으로 복구하지는 않습니다.

이미지 빌드 워크플로는 다운로드 이미지가 없는 배포 중단 버전을 건너뛰고 마지막으로 사용 가능한 릴리즈를 기반으로 빌드합니다. v1.4.4.9에서 만든 이미지나 백업을 이번 릴리즈의 기반으로 재사용하지 않는 것이 좋습니다.
