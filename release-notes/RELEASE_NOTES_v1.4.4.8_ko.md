# alpine-redpill v1.4.4.8

## 신규: 선택형 팬 센서 인식 개선

**메뉴 경로:** 메인 메뉴 → **n 추가 기능** → **v 팬 센서 인식 개선 (ACPI 제한 완화)**.

이 메뉴는 DSM 커널 명령줄의 `acpi_enforce_resources=lax`를 추가하거나 제거합니다. **기본값은 꺼짐**이며, `it87` 같은 센서 모듈이 칩을 감지했지만 ACPI 자원 충돌 때문에 연결하지 못하는 장비를 위한 선택 기능입니다. 기가바이트 H370N WIFI-CF 실기 시험에서는 옵션 적용 후 IT8628E 센서 모듈이 로드되고 팬 RPM 입력값이 활성화됐습니다.

**로더 재빌드는 필요하지 않습니다.** 설정값은 로더 구성에 바로 저장되어 다음 FRIEND → DSM 부팅에 적용됩니다. 현재 실행 중인 DSM 커널에는 즉시 반영되지 않습니다. ACPI 자원 검사 완화는 시스템 전체에 영향을 주고 일부 장비에서 불안정성을 유발할 수 있으므로, 켤 때 경고 팝업을 표시하며 필요한 경우에만 사용하도록 했습니다.

이번 기능의 직접적인 목적은 팬 RPM 입력값을 활성화하는 것입니다. 앞으로 이 값을 **MSHELL Manager의 RPM 항목**과 **cpuinfo 애드온을 통한 DSM 제어판 정보센터** 표기에도 활용할 계획입니다. 이 두 화면 연동은 이번 릴리즈에 포함된 완료 기능이 아니라 후속 계획입니다.

메뉴와 경고 문구는 지원하는 18개 언어로 번역했습니다.
