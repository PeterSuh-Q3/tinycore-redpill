# alpine-redpill v1.4.6.0

## GitHub 이슈를 통한 로더 빌드의 CPU 판정 개선

GitHub 빌더는 실제 NAS CPU가 BMI2를 지원하는지 알 수 없습니다. 이제 사용자 지정 로더 요청에서 **대상 NAS CPU의** BMI2 지원 여부를 선택하고, 그 값을 빌드에 전달합니다. 실제 NAS에서 지원을 확인한 경우에만 “BMI2 supported”를 선택하세요. 확실하지 않다면 “Unknown”을 유지하는 것이 안전합니다. 필요한 CPU 기능이 확인되지 않으면 호환되지 않는 로더를 만들기보다 빌드를 중단할 수 있습니다.

## 커널 5 플랫폼 선택의 일관성 개선

커널 5 플랫폼 선택에 별도의 메뉴 목록 대신 검토된 DSM 대상 정책을 사용합니다. 이를 통해 미지원 플랫폼 조합이 로더 선택에 섞이는 일을 줄입니다. 새 DSM 모델이나 버전이 추가되는 것은 아니며, 다른 저장소의 모듈팩이나 FRIEND 이미지까지 이 변경만으로 검증되는 것은 아닙니다.
