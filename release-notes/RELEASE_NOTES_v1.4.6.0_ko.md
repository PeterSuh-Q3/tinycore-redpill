# alpine-redpill v1.4.6.0

## GitHub 이슈 빌드의 CPU 판정 개선

GitHub 빌더는 실제 NAS CPU가 BMI2를 지원하는지 알 수 없습니다. 이제 사용자 지정 로더 요청에서 **대상 NAS CPU의** BMI2 지원 여부를 선택하고 그 값을 빌드에 전달합니다. 실제 장비에서 지원을 확인한 경우에만 “BMI2 supported”를 선택하고, 확실하지 않다면 “Unknown”을 유지하세요. 필요한 CPU 기능이 확인되지 않으면 호환되지 않는 로더를 만드는 대신 빌드를 중단할 수 있습니다.

## 커널 5 플랫폼 선택 통합

커널 5 플랫폼 선택에 메뉴별 목록 대신 검토된 DSM 대상 정책을 사용합니다. 지원 플랫폼은 epyc7002, epyc7003, icelaked, v1000nk, r1000nk, geminilakenk의 6개이며 epyc7003ntb는 제외합니다. 새 DSM 모델이나 버전이 추가되는 것은 아니며, 다른 저장소의 모듈팩이나 FRIEND 이미지까지 이 변경만으로 인증되는 것은 아닙니다.

## DSM 대상 선택 개선 (v1.4.5.9 내용 포함)

검토된 모델·DSM 버전·모듈 조합만 빌드하도록 해 DSM 커널이나 모듈팩이 맞지 않는 로더가 만들어질 가능성을 줄입니다. 원격 빌드에서는 빌더의 CPU를 실제 NAS CPU로 간주하지 않으므로 대상 장비의 CPU 정보가 필요할 수 있습니다. 새 DSM 버전이나 모델이 추가되는 것은 아닙니다.

## jq 호환성 수정

일부 jq 빌드가 DSM 릴리즈 및 커널 버전을 읽을 때 resolver의 정규식 문법을 거부해 메뉴 실행이나 대상 조회가 중단될 수 있습니다. 버전의 숫자 구성요소를 직접 검사하도록 바꿔 정규식 함수에 따른 호환성 문제를 피합니다.
