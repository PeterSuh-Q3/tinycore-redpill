# alpine-redpill v1.4.5.3

## NVIDIA 드라이버 패키지 선택

선택한 플랫폼과 DSM 커널에 게시되지 않은 드라이버 버전이 메뉴에 표시되면 설치할 수 없는 패키지를 선택할 수 있었습니다. 이제 해당 커널·플랫폼용 SPK 목록을 기준으로 선택지를 표시하고, 목록을 가져오지 못했거나 저장된 버전을 사용할 수 없으면 경고합니다.

## xTCRP 부트 메뉴 호환성

xTCRP 이미지에는 Alpine 빌드 엔트리가 사용하는 파티션이 보통 없지만, 자동화 호환성을 위해 메뉴 인덱스는 유지해야 합니다. 해당 메뉴 슬롯은 다음 슬롯과 동일하게 실행 가능한 xTCRP 설정·빌드 엔트리를 가리키고 제목만 구분합니다. 일반 Alpine 엔트리 생성 함수는 변경하지 않으며, Alpine 파티션이 있을 때 기존 방식으로 사용합니다.
