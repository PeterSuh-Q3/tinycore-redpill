# alpine-redpill v1.4.2.8

## AMD 런타임 및 Jellyfin 준비

all modules 빌드에서 지원되는 AMD 디스플레이 컨트롤러를 감지하고 최신 릴리즈에 커널 계열에 맞는 AMDGPU 런타임 패키지가 있을 때만 자동으로 내장합니다. 런타임 자동 내장은 SynoCommunity Jellyfin x64 공식 지원 플랫폼으로 제한합니다. 목록 밖 플랫폼은 AMD 커널 모듈 흐름만 유지하며 Jellyfin 런타임을 자동 설치하지 않습니다. 일치하는 패키지가 없어도 빌드는 안전하게 계속됩니다.

## MSHELL Manager 및 설정 안정성

내장 MSHELL Manager 패키지를 1.0.4까지 갱신했습니다. 릴리즈 메타데이터를 DSM 설치 훅에 전달하고 로더 빌드 전에 애드온 패키지가 확실히 포함되도록 보완했습니다. 사용자 설정 갱신 시 기존 사용자 USB cmdline 파라미터를 보존하며 잘못된 소유권도 복구합니다.

## 메뉴 및 부트 화면 보완

멀티 NIC MAC 메뉴는 각 인터페이스 처리가 끝나면 다음 인터페이스를 기본 선택하고 마지막 인터페이스 처리 후 x 종료 항목을 기본 선택합니다. 최초 Alpine 이미지용 GRUB 템플릿도 생성된 Alpine GRUB과 동일하게 gfxpayload keep을 사용하여 실물 디스플레이에서 고정 해상도 오류를 방지합니다.
