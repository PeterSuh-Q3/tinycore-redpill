# alpine-redpill v1.4.5.1

## 긴급 업데이트가 필요한 이유

v1.4.4.6 이후의 로더 업데이트 과정에서 쓰기 가능한 P3 마운트·설정 링크 또는 P4 Alpine 영속화 아카이브의 소유권이 잘못 기록될 수 있었습니다. 손상된 아카이브가 부팅 때 다시 적용되면 문제가 반복되어 메뉴 업데이트와 영속화 백업이 실패할 수 있습니다.

## 변경 사항

메뉴 시작 시 자동 영속화 백업보다 먼저 P3와 P4를 각각 검사합니다. 두 파티션이 모두 정상이면 복구와 아카이브 재작성을 건너뜁니다. 한쪽이라도 문제가 있으면 복구 후 P4 아카이브를 검증하며, 복구 결과를 확인할 수 없으면 후속 업데이트를 진행하지 않습니다. 복구 스크립트는 새 로더 이미지와 `my.sh.gz`에 포함됩니다.

동일한 안전 검사를 수동으로 실행하려면 다음 명령을 사용합니다.

```sh
curl -fsSL 'https://raw.githubusercontent.com/PeterSuh-Q3/tinycore-redpill/alpine-redpill/tools/recover-alpine-p3.sh' | sudo sh -s -- --ensure
```

`--apply`는 강제 복구용으로 유지합니다. 정기 실행과 메뉴 자동 처리에는 정상 파티션을 건드리지 않는 `--ensure`를 사용합니다.
