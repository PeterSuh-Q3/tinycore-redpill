# alpine-redpill v1.4.3.2

## 📡 새 기능: NetConsole 조기 로그 — 시리얼 케이블 없이도 부팅 로그를 실시간으로

시리얼 포트가 없는 요즘 보드에서는, 로더가 부팅 중 멈추거나 갑자기 꺼져버리면 무슨 일이 있었는지 알 방법이 없었습니다. 화면엔 아무것도 안 남고, 원인 파악이 사실상 불가능했습니다.

이번 릴리즈부터는 **부팅되는 순간부터 마지막 한 줄까지, 로그를 다른 PC로 실시간 전송**해서 받아볼 수 있습니다. 케이블 하나 없이, 네트워크로요.

> **"네트워크 기능이면 인터넷이 되고 공유기가 정상이어야 하는 거 아닌가?"** — 아닙니다. 이 기능은 인터넷도, 공유기의 DHCP도 전혀 필요 없습니다. 로더가 꽂힌 보드와 로그를 받을 PC가 **같은 스위치/공유기에 랜선으로 연결**돼 있기만 하면 됩니다. 인터넷이 끊겨 있어도, 공유기가 고장 나 있어도 상관없이 동작합니다.

### 어떻게 쓰나요

1. 메인 메뉴의 **Environment** 섹션 맨 위에 새 항목이 생겼습니다.
2. 로그를 받을 PC(리스너)의 **IP 주소만 입력**하면 됩니다. 나머지(보드 자신의 네트워크 정보, 상대방 PC의 고유 주소 등)는 전부 자동으로 알아서 채워집니다.
3. 로그를 받을 PC에서는 터미널을 열고 안내된 명령어 한 줄만 입력해두면 됩니다(macOS/Linux는 `nc`, Windows는 `ncat`).
4. 설정을 저장한 뒤 로더를 다시 빌드하면 적용됩니다. 그 다음부터는 보드가 부팅되는 순간부터, 문제가 생겨 멈추는 순간까지 모든 로그가 실시간으로 화면에 찍힙니다.

### 화면으로 보는 설정 과정

1. Environment 섹션 첫 줄의 새 메뉴 항목 ([스크린샷](../docs/netconsole/01_main_menu.png))
2. 설정하거나 끄는 걸 고르는 화면 — 지금 켜져 있는지 아닌지도 함께 보여줍니다 ([스크린샷](../docs/netconsole/02_setup_dialog.png))
3. 상대방 PC 주소를 자동으로 못 찾으면, 직접 입력하도록 친절하게 안내합니다 ([스크린샷](../docs/netconsole/03_mac_not_found.png))
4. 저장하기 전에 최종 설정값과, 로그 받을 PC에서 미리 실행해둬야 할 명령어를 한 번 더 보여줍니다 ([스크린샷](../docs/netconsole/04_save_confirm.png))
5. 저장 완료 — 지금 바로 다시 빌드해야 적용된다는 안내까지 함께 뜹니다 ([스크린샷](../docs/netconsole/05_saved.png))

메뉴 화면 전체가 **18개 언어**(한국어, 영어, 일본어, 중국어 등)로 번역되어 있어서, 어떤 언어로 쓰시든 위 화면들을 그 언어로 보실 수 있습니다.

이 모든 기능은 실제 물리 보드에 직접 설치해서 여러 차례 껐다 켜며 검증했습니다.

## 🌐 자잘하지만 중요한 개선: 업데이트가 항상 최신으로 반영되도록

로더 업데이트 파일을 받아오는 방식에 개선을 해서, 이제 개발자가 로직을 고쳐 배포하면 항상 최신 버전이 확실하게 반영되도록 했습니다. (예전엔 아주 드물게, 방금 고친 내용 대신 몇 분 전 버전이 잠깐 다시 받아지는 경우가 있었습니다.)

## 🧹 그 외 자잘한 수정

- SATA 포트 설정 화면에서 기본값을 더 넉넉하게 미리 채워주고, 자동 탐지 정확도를 높였습니다.
- 시리얼 번호/맥 주소 생성 시 화면에 표시되던 값이 가끔 엉뚱하게 나오던 문제를 고쳤습니다.
- 시스템 정보 화면(MSHELL Manager)에 표시되는 빌드 버전 정보가 더 정확해졌습니다.
- 설정 파일(usb_line)에 예전 설정값이 지워지지 않고 계속 남아있던 문제를 정리했습니다.
- 소스코드를 받아오는 과정에서 실패를 못 알아채고 그냥 넘어가던 부분을, 실패하면 바로 알 수 있도록 고쳤습니다.
- CPU 종류 판별 로직이 일부 실기 환경에서 부정확했던 문제를 고쳤습니다(구형 CPU로 잘못 인식되어 최신 모델 목록에서 일부 기종이 숨겨지던 문제).
