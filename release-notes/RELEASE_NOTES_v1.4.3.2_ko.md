# alpine-redpill v1.4.3.2

## 📡 NetConsole 조기 로그 — 시리얼 포트 없이도 부팅~패닉 로그를 실시간으로

시리얼 포트가 없는 최신 보드에서 커널 패닉이나 부팅 실패가 나면 원인을 알 방법이 없었습니다. 이번 릴리즈는 리눅스 커널 자체 기능인 **netconsole**을 로더에 통합해, 커널 로그를 UDP로 다른 PC(리스너)에 실시간 전송합니다 — **패닉 직전 마지막 한 줄까지** 받아볼 수 있습니다.

> 인터넷도 DHCP도 필요 없습니다. 같은 스위치/공유기에 물린 PC 한 대와 `nc` 명령어 한 줄이면 충분합니다.

- 🖥️ **메뉴 하나로 설정 완료 (Environment 첫 줄)**: 사용자가 입력하는 건 로그를 받을 리스너의 IP 주소 하나뿐입니다. 나머지(로더 자신의 인터페이스/IP, 리스너의 MAC 주소)는 전부 자동으로 채워집니다 — 리스너 MAC은 `ping`으로 ARP 테이블을 채운 뒤 `ip neigh`/`arp`로 자동 조회하며(자동 조회 실패 시에만 수동 입력으로 안내), 설정 시점에 한 번만 하는 조회라 부팅/패닉 시점의 불안정한 ARP에 의존하지 않습니다.
- 🧩 **netconsole.ko를 DSM 자체 `.pat`에서 조달**: 이 모듈은 부트타임 ramdisk 계열(rd.gz/all-modules) 어디에도 없고 DSM 설치본 안(`hda1.tgz`)에만 있습니다. `.pat`을 캐시 절감용 "미니팻"으로 축소하는 시점에 미리 뽑아 미니팻 자체에 영구 내장시켜서, 이후 미니팻 캐시를 재사용/재압축해도 계속 꺼내 쓸 수 있습니다.
- ⏱️ **도달 가능한 가장 이른 실행 지점**: `linuxrc.syno`의 `Main()` 함수 진입 직후 — `/proc`가 이미 마운트돼 있으면서도 DSM 파티션 마운트/본 로직(`.impl`)보다는 이른 지점 — 에서 백그라운드로 `insmod`를 시도합니다. `eth0` 실제 드라이버는 이 시점 바로 뒤에 로드되므로, 짧게 폴링 재시도(최대 60초)하며 드라이버가 올라오는 순간을 잡습니다.
- 🔧 **초경량 환경 대응**: 이 시점엔 `tr` 같은 유틸조차 아직 없어(`tr: not found`) 기존 파이프라인 파싱이 조용히 실패하던 걸, 외부 명령 없이 셸 내장 기능만으로 커맨드라인을 파싱하도록 재작성했습니다.
- 🌍 **18개 언어 전체 지원**: 메뉴 라벨부터 IP 입력창, 에러 메시지, 저장 확인창까지 하위 다이얼로그 전부 `langMenu()`가 지원하는 18개 언어(한국어/영어/일본어/중국어 간체·번체/러시아어/프랑스어/독일어/스페인어/이탈리아어/포르투갈어/헝가리어/인도네시아어/터키어/힌디어/아랍어/암하라어/태국어)로 번역되어 있습니다.

이 모든 과정을 실제 물리 보드(SA6400)에서 반복 검증했습니다 — 자동 감지/ARP 조회부터 저장/삭제 사이클, 미니팻 재압축 시 모듈 보존, `/proc` 마운트 타이밍, `tr` 부재 대응, `eth0` 준비 대기까지 전부 실기에서 재현하고 고쳤습니다.

## 🌐 GitHub raw CDN 캐시 우회

`raw.githubusercontent.com`은 경로 기준으로 최대 5분간 캐싱됩니다. push 직후 재빌드하면 방금 고친 로직 대신 구버전이 그대로 내려와 디버깅을 헷갈리게 만드는 문제를 실기로 재현했습니다. `curl`을 감싸는 wrapper 함수를 두어, 이 도메인을 향하는 모든 다운로드(`.pat`/extractor/friend 등 60여 곳 포함)에 매 요청마다 바뀌는 쿼리스트링을 자동으로 붙여 캐시를 우회합니다.

## 🧹 그 외 자잘한 수정

- **SataPortMap/DiskIdxMap**: Non-DT 모델에 넉넉한 기본값을 미리 채워두고, `showsata()`의 포트 탐지 정확도를 강화했습니다.
- **`getloaderdisk()`**: 디버그용 stdout 출력이 `sngen.sh`/`macgen.sh`의 캡처값을 오염시키던 문제를 수정했습니다.
- **`MODULES_TAG`**: `tcrp-modules` 다운로드가 `main` HEAD를 쓰는데 최신 릴리즈 태그만으로는 부정확했던 표기, "Argument list too long" 빌드 실패를 각각 수정했습니다. 빌드 시점의 LKM/모듈 태그와 로딩 방식을 `/addons/`에 기록해 MSHELL Manager의 System Info 탭이 정확한 값을 보여줍니다.
- **`usb_line` 고아 항목**: `preserve_usb_line_options()`에 새어 들어간 "LABEL: value" 형태 잔재를 정리하고, `prefillDefaultSataPortMap()` 이후 `sync_usb_line()`을 호출하도록 순서를 보강했습니다.
- **`redpill-load` clone 검증**: git clone 실패 지점을 전수 점검해 실패 시 즉시 중단하도록 했습니다.
- **`checkcpu()`**: `lscpu` 대신 `/proc/cpuinfo`를 직접 읽어, `lscpu`가 없는 실기 환경에서도 CPU 세대 판별이 정확히 동작합니다.
