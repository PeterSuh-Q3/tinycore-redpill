# alpine-redpill v1.4.6.1

## DSM 시스템 파티션 확인과 확장 신뢰성 개선

상태 화면에 설치된 DSM 모델 대신 로더에서 선택한 모델이 표시될 수 있었습니다. 이제 md0에서 실제 설치된 모델을 읽습니다. md0 확장 기능도 자동 조립된 읽기 전용 시스템 RAID를 더 신중하게 처리합니다. 선택한 시스템 파티션만 포함된 배열만 해제하고, 마운트되어 있거나 다른 멤버가 섞인 배열은 중단하며, 파일시스템 크기가 실제로 늘었는지 확인한 뒤 완료를 알립니다. 이를 통해 모델 불일치를 더 정확히 확인하고, 작은 DSM 시스템 파일시스템 때문에 설치나 업데이트가 막히는 상황에서 확장 실패를 성공으로 잘못 안내하는 일을 줄입니다.

## Non-DT 디스크 매핑 도우미

SATA 컨트롤러가 여러 개이거나 SAS HBA를 함께 사용하는 환경에서는 디스크 순서를 계획하기 어렵습니다. 새로운 도우미는 저장장치 컨트롤러와 감지된 디스크를 보여주고, 저장하기 전에 SATA 매핑 후보를 검토하도록 돕습니다.

컨트롤러 순서와 포트 수는 DSM에서 별도로 확인해야 합니다. 로더에서 감지한 디스크와 장치 순서만으로 DSM 슬롯 순서, 사용 가능한 포트 수 또는 SAS 디스크의 위치가 확정되지는 않습니다. 초기 포트 수 제안은 감지된 디스크 수를 기준으로 하므로, 특히 빈 포트가 있다면 수정해야 합니다.

도우미는 기존 SAS 설정을 보존하고 이전 SATA 매핑을 복원할 수 있습니다. 매핑 변경으로 디스크 순서가 달라질 수 있으므로, 적용 전에 제안값을 검토하고 복구 가능한 백업을 준비하십시오.

FRIEND를 통해 DSM을 부팅할 때는 저장된 명령줄 설정을 다음 부팅에서 다시 읽으므로 로더 재빌드가 필요하지 않습니다. GRUB 직접 부팅과 FRIEND를 통한 `sata_remap` 전달은 아직 검증이 필요하므로 시험 전에는 의존하지 마십시오.
