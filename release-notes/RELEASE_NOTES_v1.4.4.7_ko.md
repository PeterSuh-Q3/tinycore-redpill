# alpine-redpill v1.4.4.7

## 버그 수정

- **안정적인 Alpine 영속화 오버레이 갱신:** P3의 `localhost.apkovl.tar.gz` 기준 파일은 검증된 저장소 오버레이와 SHA-256을 비교합니다. 내용이 달라질 때만 갱신하며, 오프라인 상태나 다운로드 실패 시에는 기존 기준 파일을 안전하게 유지합니다.
- **안정적인 로더 파티션 기록:** 이미 마운트된 로더 파티션이 필요한 경우 Alpine에서 읽기·쓰기로 다시 마운트하고, P3 기록을 권한에 맞게 처리합니다. 빌드가 성공한 것처럼 보이지만 `initrd-dsm`, 세션 메타데이터, PAT 캐시, 로더 구성이 갱신되지 않던 권한 오류를 해결합니다.

램디스크는 최종 반영 전에 임시 위치에서 생성·검증됩니다. 아카이브 생성 또는 P3 기록에 실패하면 이전 `initrd-dsm`을 조용히 유지한 채 빌드가 완료되지 않고, 로더 빌드가 실패로 종료됩니다.
