# alpine-redpill v1.4.4.0

## 로더 커맨드라인 처리 안정화

- USB ID, MAC 주소, SATA DOM, i915 PSR, NetConsole, SATA 매핑 및 수동 `user_config.json` 편집을 공통 커맨드라인 동기화 로직으로 통합했습니다.
- 중복 토큰을 정리하고 오래된 관리 대상 값을 제거하여 `extra_cmdline`, `general.usb_line`, 레거시 `general.sata_line`의 일관성을 유지합니다.
- 설정을 갱신할 때 `user_config.json` 심볼릭 링크의 실제 대상은 보존하고, 이후 로더 파티션의 영속 설정도 동기화합니다.

## 빌드 시점 정합성 검증

- 빌드 결과물에 로더 설정을 복사하기 전과 생성된 `CMD_LINE`을 확정하기 전에 엄격한 검증을 추가했습니다.
- 잘못된 JSON, 중복 또는 오래된 관리 토큰, `extra_cmdline` 값 불일치, 불완전한 SATA 매핑 쌍, MAC과 `netif_num` 불일치, 잘못된 NetConsole 설정, 유효하지 않은 SATA DOM 값, i915 PSR 누락, 잘못된 커맨드라인 텍스트를 감지합니다.
- 커맨드라인 검증 실패는 경고로 계속 진행하지 않고, 빌드를 오류 코드와 함께 중단합니다.
- 메뉴는 빌드 로그 파이프라인에서도 실제 빌더 종료 코드를 유지하며, 검증 상세 내용을 전용 오류 다이얼로그로 표시합니다.

## 적용 범위

- 이번 검증은 로더 빌드 입력과 생성된 빌드 커맨드라인을 대상으로 합니다. 별도 FRIEND `boot.sh`가 런타임에 만드는 kexec 커맨드라인 검증은 추가 검증이 필요한 후속 과제로 남겼습니다.
