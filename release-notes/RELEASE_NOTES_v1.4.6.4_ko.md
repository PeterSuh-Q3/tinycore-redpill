# alpine-redpill v1.4.6.4

## 불완전한 IP 설정으로 DHCP 연결이 막히는 문제 수정

저장된 고정 IP 설정에 빈 항목이 남아 있으면 로더가 이를 유효한 고정 IP 설정으로 오인할 수 있습니다. 이 경우 DHCP 게이트웨이 처리는 억제되지만 사용할 고정 게이트웨이는 설치되지 않아 인터넷 점검과 온라인 업데이트가 실패합니다.

이번 버전은 사용할 수 없는 고정 IP 항목을 제거하고, 유효한 기본 게이트웨이가 없으면 `ipsettings`를 빈 배열로 정리합니다. 그러면 DHCP가 주소와 게이트웨이, DNS를 설정하며 유효한 고정 NIC 설정은 유지됩니다.

이전 버전에서 해당 설정 때문에 이미 인터넷에 연결되지 않는다면, 업데이트 전에 `ipsettings`를 `[]`로 바꾸어 DHCP 연결을 복구해야 합니다.
