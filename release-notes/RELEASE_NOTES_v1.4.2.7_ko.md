# alpine-redpill v1.4.2.7

## 캐시 패널 크기 선택 추가

빌드 사전 옵션 메뉴에 저장소 패널 크기 바로 아래의 **f — 캐시 패널 크기 선택** 항목을 추가했습니다. 선택한 레이아웃은 `user_config.json`의 `general.ssdbay`에 저장됩니다.

ChangePanelSize 이미지 템플릿을 기준으로 `1X1`, `1X2`, `1X3`, `1X4`, `1X6`, `1X8`, `2X2`, `2X3`, `2X4`, `2X6`, `2X8`, `3X4`, `4X4`를 선택할 수 있습니다. 기존 NVMe와 vmtools 항목은 각각 `g`, `h`로 이동했으며, 신규 UI는 18개 지원 언어 전체에 번역·컴파일했습니다.

## 하드웨어 및 빌드 메타데이터

메뉴 시작 시 릴리즈 빌드 날짜를 `general.builddate`에 기록합니다. 또한 매 시작마다 실제 메인보드 DMI 제조사·보드명을 읽어 `general.board`를 갱신합니다. 시스템 모니터는 값이 비어 있는 경우가 많은 chassis/system DMI 대신 메인보드 DMI 항목을 표시합니다.

## 로더 버너 및 부팅 화면 안정성

단독 로더 버너는 기록 전에 선택한 대상의 모든 파티션을 unmount하며, unmount에 실패하면 안전하게 중단합니다. 기존 TinyCore 로더를 변환할 때도 가능한 경우 `user_config.json`을 보존합니다.

Alpine GRUB의 `gfxpayload`를 1280x960 고정 대신 `keep`으로 변경해 실물 FHD·HD 모니터에서의 지원하지 않는 해상도 문제를 방지했습니다. 생성되는 `grub.cfg`가 깨끗하게 유지되도록 GRUB 생성 heredoc 밖으로 설명 주석도 이동했습니다.

## 메뉴 동작 개선

메인 메뉴의 섹션 헤더는 장식용 항목으로 통일해 커서를 강제로 이동시키지 않습니다. 기본 `en_US` 로케일에서 국가 코드가 감지되면, 무응답 시간 초과 시 감지된 로케일을 자동 적용합니다.
