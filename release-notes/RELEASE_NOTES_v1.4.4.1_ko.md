# alpine-redpill v1.4.4.1

## 설정 저장 안내 체계

- 사용자가 메뉴에서 설정을 저장한 뒤 결과를 일관되게 안내하는 다이얼로그를 추가했습니다.
- 현재 세션에 즉시 적용되는 설정, 재빌드 없이 다음 FRIEND에서 DSM으로 부팅할 때 적용되는 커맨드라인 설정, 다음 관련 동작에서 사용되는 설정, 로더 재빌드가 필요한 설정을 명확히 구분합니다.
- 기본 MODEL, DSM 버전, SN, MAC 주소 선택 흐름은 곧바로 빌드 단계로 이어지는 기본 절차이므로 중복 저장 안내를 표시하지 않습니다.

## 안전한 커맨드라인 설정 변경

- 커맨드라인 변경은 설정 트랜잭션으로 처리합니다. 동기화된 커맨드라인을 검증하는 동안 이전 `user_config.json`을 보관합니다.
- 검증에 실패하면 이전 설정을 자동으로 복원합니다. 오류 다이얼로그에는 이전값, 거부된 값, 검증 오류 원인을 표시합니다.
- SATA DOM, i915 PSR, NetConsole, SATA Remap 및 수동 `user_config.json` 편집에 이 보호를 적용했습니다.
- 유효한 `syno_hw_version` 모델값의 끝 `+` 문자는 정상값으로 허용하면서, 그 밖의 잘못된 커맨드라인 문자열 결합은 계속 차단합니다.

## 런타임과 빌드 안내

- 고정 IP 및 GitHub DNS 또는 DoH 변경은 실행 중인 로더 세션에 즉시 적용되었다고 안내합니다.
- 애드온, 모듈 프로필, 장치 관리자 방식 변경은 로더 재빌드가 필요한 경우를 명시적으로 안내합니다.
