# alpine-redpill v1.4.7.2

## Alpine OpenSSH 보안 보완

Alpine OpenSSH의 암호 인증은 CVE-2026-123158의 영향을 받을 수 있습니다. 서버에도 보안 수정 버전이 적용되도록 `openssh`와 `openssh-server` 모두 `10.3_p1-r2` 이상을 요구합니다. 이 기준은 Alpine 로더에 적용되며 DSM의 SSH 서비스와는 별개입니다.

## 오프라인 Wi-Fi 검색 도구

새 Alpine 로더 이미지의 로컬 패키지 저장소에 `iw`와 의존성을 포함합니다. 부팅 시 도구를 인터넷에서 다운로드하지 않아도 사용할 수 있도록 하기 위한 것입니다. 무선 검색에는 호환 무선랜과 드라이버가 필요하며, `iw`만으로 Wi-Fi에 연결되지는 않습니다.
