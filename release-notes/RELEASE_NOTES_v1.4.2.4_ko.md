# alpine-redpill v1.4.2.4

다국어 처리와 메뉴 정리 중심의 릴리즈입니다.

## 메뉴 다국어 처리 완료

메인 메뉴와 하위메뉴에 남아 있던 하드코딩 영문 문자열을 전부 지원하는 18개 언어로 번역했습니다. 그동안 NVIDIA 트랜스코딩 하위메뉴, Verbose Mode, 이전 버전 재빌드, TCB/FKC 자동 업데이트 관리, 그리고 추가 기능·Syno 디스크 처리 하위메뉴의 일부 항목은 어떤 언어를 선택해도 영어로만 표시되던 상태였습니다.

버전 번호와 기술 식별자(`NVIDIA`, `ffmpeg`, `Jellyfin`, `DDSML/EUDEV`, `Status`, `ON`/`OFF`, `ENABLED`/`DISABLED`)는 기존 메뉴의 표기 방식과 동일하게 모든 언어에서 영어 그대로 유지됩니다.

## Verbose Mode 하위메뉴를 다이얼로그 방식으로 변경

Verbose Mode 화면은 `echo`로 그리는 텍스트 프롬프트라 다른 메뉴들과 이질적이었고, 콘솔 출력에 덮여 지워질 수도 있었습니다. 이제 나머지 인터페이스와 동일한 다이얼로그 창으로 동작하며, 기존과 같은 1/2/3 항목 인덱스를 그대로 사용합니다.

이 과정에서 발견한 크기 문제도 함께 수정했습니다. 높이를 자동으로 두면 상자가 24행 콘솔을 넘겨 dialog가 실패하고, 하위메뉴가 열리자마자 닫히는 현상이 있었습니다.

## 이전 버전 재빌드의 저메모리 안내

이전 버전 재빌드에는 최소 6GB 메모리가 필요합니다. 이를 알리는 메시지가 콘솔에 그대로 출력돼, 메뉴가 다시 그려지면서 덮이거나 스크롤로 밀려 나가 못 보고 지나치기 쉬웠습니다. 이제 확인을 받고 메인 메뉴로 돌아가는 다이얼로그 팝업으로 표시됩니다.
