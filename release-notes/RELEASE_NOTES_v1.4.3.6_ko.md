# alpine-redpill v1.4.3.6

## 🌐 저장된 고정 IP가 이제 매 부팅마다 자동으로 반영됩니다

이전에는 고정 IP가 최초로 저장되는 그 순간에만(DHCP 3회 실패 후 뜨는 오프라인 설정 다이얼로그를 거쳐서) 실제로 사용됐습니다. 그 이후 재부팅할 때마다 `menu.sh`는 `user_config.json`에 이미 저장돼 있는 고정 IP 설정을 무시하고, 절대 성공할 수 없는 네트워크에서도 매번 처음부터 DHCP 대기/재시도를 반복했습니다.

- 🔌 네트워크 설정 단계 맨 처음, DHCP 시도 이전에 새로 추가된 `apply_saved_static_ip()`가 확인합니다. `ipsettings.ipset`이 이미 `"static"`이면 저장된 IP/게이트웨이/DNS/프록시를 이 로더 세션에 바로 적용합니다.
- ⏭️ 저장된 고정 IP가 적용된 경우 3회 NIC kick/DHCP 재시도 루프를 통째로 건너뜁니다 — DHCP 서버가 없는 네트워크에서는 애초에 성공할 수 없으므로 매 부팅마다 기다릴 이유가 없습니다.
- 🚫 이 경우 오프라인 고정 IP 설정 다이얼로그도 다시 뜨지 않습니다 — 이미 적용 중인 값을 다시 입력하라고 묻는 셈이기 때문입니다.

v1.4.3.5에서 추가된 오프라인 최초 설정 경로와 그 이후의 매 부팅 사이에 있던 공백을 메웠습니다 — 이제 고정 IP를 한 번 저장하면 설정한 그 부팅뿐 아니라 이후 모든 부팅에서 일관되게 적용됩니다.
