# alpine-redpill v1.4.5.7

## 대용량 선택 패키지를 로더 이미지에서 분리

MSHELL Manager, Syno Smart Info, 그리고 지원되는 AMD 시스템의 AMD GPU Runtime 패키지를 로더 빌드 때 DSM initrd에 통째로 넣으면 이미지가 크게 늘어날 수 있습니다. 이제 로더에는 검증된 릴리즈 정보만 포함하고, DSM의 패키지 서비스가 준비된 뒤 마운트된 데이터 볼륨으로 패키지를 내려받아 크기와 SHA-256을 확인한 다음 설치합니다. 이미 같은 버전 또는 더 최신 버전이 설치되어 있으면 다시 설치하지 않습니다. 다운로드나 서비스 준비가 일시적으로 실패해도 DSM 부팅을 막지 않고 다음 부팅에서 재시도할 수 있습니다. 일반 DSM 부팅 경로는 바꾸지 않으면서 initrd 크기를 줄입니다. post-boot 설치 흐름은 격리된 로더 이미지와 모의 테스트를 통과했으며, 실제 DSM 시스템에서의 전체 설치 검증은 아직 남아 있습니다.

## 지원되는 환경에서 NVIDIA 모듈 종류 선택

지원되는 커널 5.10.55 환경의 NVIDIA 드라이버 메뉴에 호환 드라이버 브랜치의 Open 및 Proprietary 모듈 선택지가 추가되었습니다. Open 모듈은 Turing 이상 GPU에서만 선택할 수 있고, 그보다 오래된 지원 GPU는 Proprietary 모듈을 사용합니다. 나머지 드라이버 옵션은 그대로 두고 하드웨어에 맞는 모듈 종류를 선택할 수 있습니다.

## 선택한 하드웨어에 맞는 옵션과 정보 표시

NVMe 매핑 메뉴는 PAS7700을 선택한 경우에만 데이터 볼륨 매핑으로 표시하고, 그 외 모델에는 M.2 캐시 매핑으로 안내합니다. 시스템 모니터에는 감지된 디스플레이 GPU 목록도 표시되어 다중 GPU 환경을 설정할 때 장치를 구분하기 쉬워졌습니다.

PCI 모듈 제안 기능은 선택된 커널에 맞는 alias 색인을 사용합니다. 색인이 없을 때는 선택적 제안 단계만 명확한 경고와 함께 건너뛰며, 파일 누락을 JSON 파싱 오류처럼 표시하지 않습니다. 디스플레이/KMS 안정성을 조사하는 동안 Junior Realtime Helper의 모델 목록 자동 추가는 보류했습니다. 따라서 이번 버전에서는 모델 선택만으로 이 애드온이 자동 추가되지 않습니다.
