# alpine-redpill v1.4.5.2

업데이트 직후에는 새 시작 점검이 적용되기 전에 기존 메뉴 프로세스가 영속화 백업을 시작할 수 있습니다. 이제 Alpine 백업 전에 P3/P4를 확인하고 복구하며, 점검이나 복구를 완료할 수 없으면 백업을 중단합니다. 손상된 파티션 상태나 영속화 파일이 다시 저장되는 일을 막기 위한 조치입니다.

롤백이 필요할 때 메인 메뉴에서 이전 로더 릴리즈를 선택해 재빌드하는 기능도 복구했습니다. 안정 릴리즈 목록은 동적으로 가져와 검증하며, 이 기능에는 메모리 6GB 이상이 필요합니다.

- P3/P4 영속화 불안정성이 확인된 v1.4.4.9는 선택 및 빌드 대상에서 제외했습니다.
- 마지막 안정 롤백 기준은 v1.4.4.8입니다.
