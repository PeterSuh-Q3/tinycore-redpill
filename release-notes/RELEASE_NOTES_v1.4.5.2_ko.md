# alpine-redpill v1.4.5.2

이전 구버전 선택빌드 기능 개선.

## 이전 릴리즈 선택

- 고정된 이전 버전 목록을 GitHub 안정 릴리즈에서 실시간으로 불러오도록 변경했습니다.
- `v1.2.7.7`부터의 태그를 화면 크기에 맞는 버전 구간으로 나누며, 각 구간에는 최대 20개 태그만 표시합니다.
- 태그 설명에는 릴리즈 노트의 의존성 커밋 해시 3줄 다음에 나오는 첫 번째 설명 줄을 사용합니다.
- 버전 전환 전에 태그, 세 의존성 해시, 다운로드한 스크립트를 검증합니다. 검증이나 다운로드가 실패하면 현재 스크립트로 조용히 대체하지 않고 오류로 중단합니다.
- 기존 6 GB 최소 메모리 조건은 유지됩니다.
