# alpine-redpill v1.4.4.5

## RS11626xs+ 모델 지원 추가

- RS11626xs+ 모델을 epyc7003 Device Tree 모델 그룹에 추가했습니다.
- 이 모델은 커널 5.10 플랫폼 프로필과 RACK_20_Bay 스토리지 레이아웃을 사용합니다.

## 반응형 Alpine 데스크톱 세션

- Alpine SX의 네 개 터미널이 현재 디스플레이 해상도에 맞는 2x2 반응형 레이아웃을 사용합니다.
- 사용 가능한 화면 영역에 맞춰 터미널 크기 좌표 글꼴 크기를 조정합니다.
- 시작 후 MSHELL Menu 터미널을 전면으로 활성화해 초기 키보드 포커스를 개선했습니다.
- 재부팅 후에도 필요한 tc staff 소유권이 유지되도록 Alpine 사용자 설정 파일의 영속화 처리를 보완했습니다.

## 안정적인 빌드 백업

- 로더 빌드 백업이 성공하면 메뉴의 구성 기준값을 즉시 갱신합니다.
- 빌드가 끝난 직후 재부팅해도 동일한 백업이 다시 실행되지 않습니다.
- 빌드 후 백업 실패를 성공으로 처리하지 않고 빌드 실패로 반환합니다.

## 선택형 SAN Manager 복구

- sanmanager-repair를 기본 확장 번들에서 제거했습니다.
- SAN Manager 패키지 문제가 발생한 경우에만 빌드 사전 옵션 메뉴에서 활성화하거나 제거할 수 있습니다.
